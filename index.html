iOS Home Screen Installation

  1. Open Safari on your iPad.
    Visit .
  2. Enter the requested information.
    Fill in the app name, bundle ID, version, platform, minimum OS, and file size.
  3. Generate the App Store preview.
    Tap Generate App Store Preview and review the result.
  4. Get the installation instructions.
    Tap Get to display these instructions.
  5. Add the app to the Home Screen.
    In Safari, tap Share → Add to Home Screen → enter the desired name → Add.
  6. Launch the app.
    Return to the iPad Home Screen and tap the new icon.

This creates a Home Screen web app/PWA shortcut. It does not submit or install a native App Store package.

For a fully installable PWA, add a service worker and the actual 192×192 and 512×512 PNG icons referenced by the manifest.
