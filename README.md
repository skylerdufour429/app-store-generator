# iOS 3.1 Home Screen Installation Instructions

Follow these instructions to install and launch the App Store Generator as a web app on your iPad.

## 1. Open Safari on Your iPad

Open **Safari** on your iPad and visit the App Store Generator:

https://skylerdufour429.github.io/app-store-generator/

## 2. Create Your App

Enter the requested information into the **App Store Generator**:

* **App Name:** `[Paste App Name Here]`
* **Bundle ID:** `[Paste Bundle ID Here]`
* **Version:** `[Paste Version Here]`
* **Platform:** `[Paste Platform Here]`
* **Minimum OS:** `[Paste Minimum OS Here]`
* **File Size:** `[Paste File Size Here]`

## 3. Generate the App Store Preview

Tap **Generate App Store Preview**.

Review the generated app information and preview to make sure everything is correct.

## 4. Get the Installation Instructions

Tap the **Get** button.

The generator should display instructions explaining how to add the web app to your iPad Home Screen.

## 5. Add the App to the Home Screen

1. Tap the **Share** button in Safari.
2. Select **Add to Home Screen**.
3. Enter the desired app name.
4. Tap **Add**.

## 6. Launch the App

1. Return to the iPad **Home Screen**.
2. Locate the newly added app icon.
3. Tap the icon to launch the web app.

## Notes

* Make sure you are using **Safari** when adding the app to the Home Screen.
* The generated app is a **web app shortcut/PWA**, not a native App Store installation.
* An internet connection may be required for features that load content from the web.
