# iOS 3.1 Home Screen Installation Instructions

1. **Open Safari** on your iPad.

2. **Visit the App Store Generator:**
   [App Store Generator](https://skylerdufour429.github.io/app-store/)

3. **Create your app** using these settings:

   * **App Name:** `[Paste App Name Here]`
   * **Bundle ID:** `[Paste Bundle ID Here]`
   * **Version:** `[Paste Version Here]`
   * **Platform:** `[Paste Platform Here]`
   * **Minimum OS:** `[Paste Minimum OS Here]`
   * **File Size:** `[Paste File Size Here]`

4. **Install the app:**

   * Tap the **Share** button in Safari.
   * Select **Add to Home Screen**.
   * Enter the app name.
   * Tap **Add**.

5. **Launch the app:**

   * Return to your iPad Home Screen.
   * Tap the new app icon to launch it.
